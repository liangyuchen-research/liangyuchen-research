# Liang-Yu (Lio) Chen

M.S. student in Chemical Engineering at **National Taiwan University**. I work on machine learning for plasma spectroscopy, experimental automation, and signal processing.

## Research

| Project | Focus |
| --- | --- |
| [Autonomous Laboratory](https://github.com/liangyuchen-research/laboratory-instrument-control) | Automated solution preparation and quantitative analysis. FastAPI, Arduino firmware, a touch console, and mass-feedback dosing for eight peristaltic pumps. **NTU** |
| [GAN-Based Spectral Restoration](https://github.com/liangyuchen-research/conditional-gan-spectral-restoration) | Conditional GAN restoration of plasma spectra for real-time heavy metal quantification across solution matrices. **NTU** |
| [SWOT Satellite Wave Separation](https://github.com/liangyuchen-research/ocean-satellite-wave-separation) | Denoising autoencoders for separating ocean-wave signals in satellite altimetry. **Scripps Institution of Oceanography, UC San Diego** |
