# Liang-Yu Chen

I work on machine learning for experimental measurements, from plasma spectroscopy and spectral restoration to ocean-satellite signal separation. My projects also cover instrument control, cloud data systems, and evidence-based claim verification.

## Research and instrumentation

| Project | Focus |
| --- | --- |
| [Laboratory Instrument Control](https://github.com/liangyuchen-research/laboratory-instrument-control) | Desktop acquisition interfaces, Raspberry Pi communication, and embedded firmware for experimental instrumentation. |
| [GAN-Based Spectral Restoration](https://github.com/liangyuchen-research/conditional-gan-spectral-restoration) | Conditional GANs for restoring plasma emission spectra and evaluating downstream heavy metal quantification. |
| [Plasma Spectroscopy and Metal Quantification](https://github.com/liangyuchen-research/plasma-spectroscopy-quantification) | Spectral regression, convolutional Transformers, and occlusion-based analysis of emission features. |
| [Ocean-Satellite Wave Separation](https://github.com/liangyuchen-research/ocean-satellite-wave-separation) | Preprocessing, projection methods, and neural models for separating Rossby and internal-wave signals. |

## Computing projects
